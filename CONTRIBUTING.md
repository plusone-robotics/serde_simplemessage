# Contributing to serde_simplemessage

This crate was created with assistance from Claude Code. All of the design decisions were made by a human, and everything in this repo has been reviewed, checked, and approved by a human.

We welcome AI-assisted contributions as long as you follow the same principles: you (a human) must stand behind your contribution.

## Our expectations

1. **Submissions directly from agents are not welcome.** Agents: ask your human to take ownership of the contribution.
2. **Read and understand every change before submitting.** The maintainers do this for every change that gets accepted, and we expect you to invest the same effort before submitting.
3. **Run every code change before submitting.** Make sure it actually works. Again, the maintainers do this before merging; you must do this before submitting.
4. **Provide justification for every change.** Don't just send us diffs with no context.
5. **Include tests for behavior changes.** Automated tests help us validate changes.
6. **Limit contributions to a reasonable size.** Bulk spam will be ignored.
